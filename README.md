# Разбор партий

Веб-приложение, которое загружает ваши партии с chess.com, прогоняет каждую через Stockfish прямо в браузере и показывает, где и почему вы теряете очки.

## Возможности

- Загрузка последних партий по нику chess.com (фильтр по контролю времени) или вставка PGN
- Оценка каждой позиции движком Stockfish 10 (WebAssembly, в Web Worker)
- Классификация ходов: зевок / ошибка / неточность по падению шансов на победу (формула lichess)
- Тип ошибки: фигура под боем, фигура без защиты, тактика соперника, угроза мата, упущенная тактика, позиционная
- Статистика по стадиям партии, типам ошибок, дебютам и времени на ход
- Персональные выводы «над чем работать»
- Просмотр партии с доской, шкалой оценки, стрелками лучшего хода и угрозы, кнопкой «Следующая ошибка»
- Кэш анализа в `localStorage`

## Запуск

```bash
node serve.js
```

Откройте http://localhost:8765.

Нужен только Node.js — зависимости уже лежат в `vendor/`.

## Устройство

| Файл | Назначение |
|---|---|
| `index.html`, `style.css` | Разметка и стили |
| `app.js` | Вся логика: загрузка, анализ, статистика, отрисовка |
| `serve.js` | Минимальный статический сервер |
| `vendor/chess.js` | [chess.js](https://github.com/jhlywa/chess.js) — правила, PGN, FEN (BSD-2-Clause) |
| `vendor/stockfish.*` | [stockfish.js](https://github.com/nmrugg/stockfish.js) — Stockfish 10 в WebAssembly (GPL-3.0) |

## Лицензия

GPL-3.0, так как проект распространяет Stockfish.
